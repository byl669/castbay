## 开始使用

### 支持哪些设备？

Android 6.0 及以上的安卓设备：电视、电视盒子、车机和平板都可以，用遥控器或触摸屏操作。已在小米（Android 6）、TCL（Android 9）和索尼（Android 12）电视、Google TV Streamer 以及比亚迪 DiLink 5.0 车机（Android 12）上测试，详见[兼容性列表](/zh/compatibility)。

### 如何把 APK 安装到电视上？

可以用电视浏览器（输入 `castbay.weenas.com/apk`）、U 盘、手机推送、电视上的 App 或电脑上的 adb 安装。第一次安装时，电视会询问是否允许从这个来源安装应用。[使用指南](/zh/guide#安装和更新)里有每种方式的详细步骤、小米/TCL/索尼/Google TV 的设置位置，以及安装失败的处理办法。

### 下载的 APK 可信吗？

每个正式版都由 GitHub 根据打了标签的源代码自动构建，不经过任何人的电脑，并用映湾自己的密钥签名，发布前会自动检查签名是否正确。每个版本都附有对应的完整源代码。另外，安卓只允许签名相同的版本覆盖安装，被篡改的安装包无法替换你已经装好的映湾。

### 在哪里可以下载映湾？不同渠道之间能互相升级吗？

有两个渠道：

- **本网站或 GitHub**（[CastBay.apk](/apk)、[所有版本](https://github.com/weenas/castbay/releases)）：使用映湾自己的签名。映湾会自动检查新版本，在"关于"页里就能下载安装。也可以用 [Obtainium](https://github.com/ImranR98/Obtainium) 跟踪 GitHub 上的新版本（同一个签名，可以互相升级）。
- **F-Droid**（已提交，审核中）：由 F-Droid 自己从源码编译并用 F-Droid 的签名发布；通过 F-Droid 客户端更新，映湾本身不会检查更新。

安卓只允许用签名相同的版本覆盖安装，所以**F-Droid 版和其他渠道的版本不能互相覆盖升级**：要换渠道，需要先卸载映湾（设置和已允许的设备会一并清除），再从另一个渠道安装。本网站和 GitHub 之间切换则不需要卸载。

## 连接

### 手机上找不到电视怎么办？

确认电视和手机在同一个 Wi-Fi 下，并且映湾已经打开并显示"等待投屏连接"。有些路由器开启了"AP 隔离"，会阻止设备互相发现，需要在路由器设置里关闭。也可以试试把手机的 Wi-Fi 关掉再打开。

### 为什么安卓手机上的 YouTube 找不到映湾？

安卓版 YouTube 的这一投屏方式使用 Google Cast，映湾目前不支持接收。可以直接用电视上的 YouTube App，或者用 iPhone、iPad 投送（它们的 YouTube 使用 AirPlay）。带 DLNA 投屏按钮的 App（哔哩哔哩、爱奇艺、网易云音乐等）在安卓手机上可以正常使用。

### 支持 Google Cast（Chromecast）或 Miracast 吗？

目前不支持 Google Cast／Chromecast 投送及镜像，也不支持 Miracast。请使用 AirPlay 或 DLNA；具体已验证的功能和设备见[兼容性](/zh/compatibility)。

### 能从 Mac 投音乐吗？

Mac 的屏幕镜像可以用。Mac 上"音乐"App 的投送暂不支持：它使用的加密方式，映湾所基于的开源 AirPlay 库无法兼容。

## 投屏和播放

### 为什么 AirPlay 音乐的进度条不能拖动？

因为 AirPlay 不让电视决定从哪里开始播放。歌曲是手机在播放，它会把声音提前一点发给电视，并标好每一段应该在什么时候播出，电视只负责按时播放收到的内容。电视能发回手机的只有几个遥控命令（播放、暂停、上一首、下一首），没有"跳到某个时间"，所以 Apple TV 的遥控器也不能拖动 AirPlay 音乐的进度。因此进度条只显示播放到哪里，调进度请在手机上操作。

DLNA 音乐不一样：文件是电视自己下载播放的，所以进度条可以拖动；App 投送的视频（AirPlay 或 DLNA）也都可以拖动进度条。

### 为什么音乐要等两秒左右才响？

这是为了和手机保持同步。iPhone 会提前约两秒把音乐发给电视，并标上每一段应该播出的时刻，映湾按这个时刻播放，和 Apple TV 一样。这样歌词始终同步，暂停后恢复也能无缝接上。详见[技术原理](/zh/tech)。

### 屏幕镜像有点延迟，正常吗？

有一些延迟是正常的，Apple TV 也一样：发送端要先截取并压缩画面，电视才能显示。有两个办法可以缩短延迟。一是把电视的画面模式切换为**游戏**：电视会对画面做美化处理，我们测试的索尼电视仅这一步就要 160 毫秒。二是用 Mac 投到 4K 电视时，选用 1080p：Mac 编码 1080p 画面比 4K 快得多。可以在映湾里把**最高分辨率**设为 1080p，也可以在投屏时到 Mac 的“系统设置 → 显示器”里为 CastBay 选择分辨率（Mac 会记住这个选择）。实测（MacBook 投到索尼 4K 电视）：标准画面模式下延迟约 350 毫秒，游戏模式约 190 毫秒，游戏模式加 1080p 不到 100 毫秒。播放统计信息里的 decode 显示电视解码所占的时间，一般在 10–20 毫秒。

### 视频无法播放？

从 App 投送的视频由电视直接从网上获取。如果手机要通过代理或 VPN 才能打开（例如 YouTube），电视也需要能访问。屏幕镜像不受影响，因为画面来自手机。

### 为什么哔哩哔哩投屏只有 720P？

哔哩哔哩只把 1080P 及以上的清晰度开放给它的官方电视 App，投到第三方设备最高是 720P。想看 1080P 可以用屏幕镜像。

### 怎么在电视或车机上结束投屏？

连按两次返回键（遥控器上的返回键，或车机、平板的返回键/返回手势）。按主页键则会让投屏在后台继续播放。

### 在车机上，每次启动车辆后都要手动打开映湾吗？

在比亚迪车机上需要。车机熄火时不是关机，而是休眠，并且会强行停止所有第三方应用（映湾的诊断信息里显示为"stop … due to quickboot"）。按照安卓的规定，被强行停止的应用在被手动打开之前，收不到任何系统通知，也不会运行后台任务，所以映湾没法在车辆启动后自己恢复。建议把映湾放在车机桌面或常用应用栏里，上车后点一下即可；打开后会一直接收投屏，直到熄火。

在电视和不会强行停止应用的设备上，映湾会在开机或唤醒后自动开始接收投屏。

### 为什么修改设置后投屏断开了？

连接和屏幕镜像类的设置（设备名称、投屏验证、分辨率等）需要重启接收器才能生效，正在投屏的设备要重新连接。画面比例、统计信息、歌词等播放类设置则立即生效，不会打断投屏。

## 隐私和安全

### 能阻止别人投屏到我的电视吗？

可以。在设置 → 连接 → 投屏验证中选择"电视确认"（新设备投屏前电视会询问）、"PIN 码"（新设备第一次投屏时输入电视显示的 PIN 码）或"密码"。投屏过的设备也可以在那里单独拒绝。从应用自带的投屏按钮（DLNA）投屏时，选三者中任何一种，都由电视确认。

### 映湾会收集我的数据吗？

不会，除非你主动选择。映湾不需要账号，没有广告，也没有第三方统计。只有在你自己开启时才会发送数据：打开"显示歌词"后，会把歌名和歌手发送到 lrclib.net 查询歌词；在"关于 → 诊断信息"里上传问题报告，或者映湾意外退出后你同意发送报告（或打开了"自动发送错误报告"）时，会把应用最近的日志发送到本网站，歌名、设备名称、网址和公网 IP 会先去掉。匿名使用统计（投屏和出错的次数，不含任何名称或歌名）只有在你打开"设置 → 通用 → 发送匿名使用统计"后才会发送。每日检查更新不会发送任何与你有关的信息。详见[隐私政策](/zh/privacy)。
