映湾（CastBay）是一款运行在安卓大屏（电视、车机、平板）上的开源投屏接收 App。我们重视你的隐私：映湾不需要账号，不含广告，也不包含任何第三方统计或追踪代码。

## 我们收集的信息

默认不收集任何信息。映湾不会收集你的个人信息，也不会自行把你的使用情况发送给我们或任何第三方。我们只可能从 App 收到两种数据，而且都要你自己开启：[问题报告](#问题报告仅在你主动发送时)（上传前会先去掉个人信息），以及[匿名使用统计](#使用统计仅在你打开时)。

## 投屏内容

- 通过 AirPlay 投屏时，画面和声音只在你的手机与电视之间、在你的局域网内传输。
- 通过 App 投送视频或音乐时（AirPlay 视频或 DLNA），电视会直接从该 App 提供的地址下载并播放内容。这与在电视上直接观看该内容相同，相关的数据处理由提供内容的服务负责。
- 映湾在局域网内发布设备名称，以便你的手机能找到它。

## 歌词（可选功能）

"显示歌词"默认关闭。开启后，播放音乐时映湾会把歌曲的名称、歌手、专辑和时长发送到 [lrclib.net](https://lrclib.net)，用于查询歌词。请求中不包含任何可以识别你身份的信息。该网站的数据处理适用其自身的政策。你可以随时在设置或播放时的快捷菜单中关闭此功能。

## 检查更新

映湾每天向本网站（castbay.weenas.com/latest.json，网站无法访问时经由[中转服务器](#中转服务器castweenascom)）查询一次最新版本号，仍然不行时改为查询 GitHub（api.github.com），以便在有新版本时提示你。请求中不包含任何与你或你的电视有关的信息；和访问任何网页一样，服务器会看到你的网络地址（本网站由 Cloudflare 托管，GitHub 适用其自己的政策）。你可以在设置的"通用"页中关闭此功能。

如果你在设置的"通用"页中打开了**接收测试版本**（默认关闭），映湾还会向 GitHub（api.github.com）查询映湾的发布列表（包括测试版本），以便在"关于"页提供测试版本的更新。这个请求同样不包含任何与你或你的电视有关的信息；GitHub 会看到你的网络地址，适用其自己的政策。

只有在"关于"页点击**下载并安装**后，映湾才会从本网站或 GitHub 下载新版本，核对它与发布的文件完全一致（SHA-256），再打开安卓的安装界面，由你确认更新。映湾不会自行下载或安装任何东西。

## 问题报告（仅在你主动发送时）

只有两种情况会发送问题报告，都由你决定：

- **你主动上传**：关于 → 诊断信息 → **上传日志**，适合没法连接电脑调试的设备（例如车机）。确认页面会列出将要发送的内容，只有你点击"上传"后才会发送。
- **映湾意外退出后**（崩溃，或者因无响应被安卓关闭）：下次启动时，主界面会询问是否发送这次问题的报告，只有你点击"发送"才会发送。如果你打开了**自动发送错误报告**（设置 → 通用，默认关闭），这类报告会直接发送，不再询问；关闭这个开关即可停止。

**报告包含的内容**

- 设备信息：厂商、型号、Android 版本和系统版本号、屏幕尺寸和密度、是否为触摸屏、映湾的版本，以及设备已开机多长时间。
- 诊断信息页上的事件：映湾的启动和停止、遥控器和方向盘按键、点击、音频焦点，以及上次退出的原因。
- 映湾自己最近的运行日志（最多约 400 KB）：接收器做了什么，例如连接、视频格式和解码器、出错信息。安卓只允许 App 读取自己的日志，读不到其他 App 的。
- 意外退出后的报告还包括：错误信息和它在映湾代码中发生的位置（调用栈），以及出错前映湾的几百行日志。
- 如果映湾上一次运行是在接收投屏时结束的，而且不是映湾自己停止的（崩溃，或者被安卓关闭）：那一次运行最后的日志，内容同上。

**发送前在本机去掉的内容**

- 歌曲和视频的名称、歌手、专辑，以及投屏的手机和电脑的名称（例如"小明的 iPhone"）。
- 网址（播放内容的地址）、PIN 码和密码、邮箱地址和硬件（MAC）地址。
- 公网 IP 地址。局域网地址（例如 192.168.1.5）会保留，它有助于排查网络问题，而且不能反映你的位置。

**发送到哪里、保存多久**

报告通过 HTTPS 发送到本网站（castbay.weenas.com，由 Cloudflare 托管），保存 90 天后自动删除。只有开发者能查看，没有公开链接。上传后你会得到一个报告编号（例如 CB-7K3F9Q），反馈问题时附上即可；除此之外，报告和你没有任何关联。你的网络地址只用来限制短时间内的上传次数，不会和报告一起保存。如果希望提前删除某份报告，请在 [GitHub](https://github.com/weenas/castbay/issues) 上提交问题并附上报告编号。

## 使用统计（仅在你打开时）

**发送匿名使用统计**（设置 → 通用）默认关闭，关闭时不做任何统计。打开后，映湾会生成一个随机的安装 ID（与设备和你本人无关），在本机统计每天的使用情况，每天一次把前一天的汇总发送到本网站：

| 发送的内容 | 示例 |
| --- | --- |
| 随机安装 ID 和日期 | 3f2a…、2026-10-02 |
| 映湾的版本 | 1.2.0 |
| Android 版本、设备厂商和型号 | 12、Xiaomi MiTV4 |
| 屏幕档位、设备类型、是否触摸屏 | 1080p、电视、否 |
| 系统语言 | zh |
| 当天各类投屏的次数 | AirPlay 屏幕镜像 3 次、DLNA 视频 1 次 |
| 投屏时长（分三档） | 不到 1 分钟 2 次、1–10 分钟 1 次、超过 10 分钟 1 次 |
| 屏幕镜像的分辨率档位和编码 | 1080p H.264：3 次 |
| 出错次数（按类型） | 接收器 0、视频解码器 1、视频播放 0 |
| 正在使用的设置 | 投屏验证：PIN 码；DLNA 开；歌词关；分辨率：自动 |

不会发送：设备名称（电视或手机的）、歌曲和视频名称、网址、网络地址和硬件地址、Wi-Fi 名称、你的位置、每次投屏的具体时间、密码和 PIN 码。本网站在数据库（Cloudflare D1）中按安装 ID 和日期每天保存一行，不保存你的网络地址，一年后自动删除。只有开发者能查看，用来了解需要支持哪些设备和 Android 版本、映湾在哪里出问题。**关闭这个开关**会停止统计、删除安装 ID，并请求本网站删除这个 ID 下发送过的所有数据。

## 中转服务器（cast.weenas.com）

在部分网络中（常见于中国大陆），托管在 Cloudflare 上的本网站无法访问。这时映湾会把同样的三类请求（检查更新、问题报告、使用统计）改发到 cast.weenas.com：这是开发者在美国的服务器上运行的中转服务，通过 HTTPS 把请求原样转给本网站，再把回应传回来。它不保存任何内容，不记录访问日志，也不提供其他任何服务。它会把你的网络地址告诉本网站，仅用于上文所说的上传次数限制，本网站同样不会保存。发送和保存的内容与上文描述完全一致。

## 设置和本机数据

你的设置（例如设备名称、投屏密码）只保存在电视本机，不会上传；投屏过的设备列表（设备名称和 AirPlay 设备 ID、是否允许，以及通过 PIN 码配对的设备的配对密钥）也一样。你可以在设置中移除这些设备，卸载映湾会一并删除所有数据。

"关于 → 诊断信息"里的记录（最近的启动、按键、点击和音频焦点事件，以及设备型号、系统版本和屏幕尺寸）同样只保存在本机，最多保留最近 120 条，只在你打开这一页时显示，可以随时清除；只有在你主动上传问题报告时才会离开设备。

映湾还会在自己的本机存储里保留最近的运行日志（本次和上一次运行的，最多几百 KB），以便问题报告能看到崩溃之前发生了什么。其他 App 读不到它；只有在你发送问题报告时才会离开设备，并且同样会先去掉上面所说的个人信息；卸载映湾会一并删除。

## 权限说明

- 网络：接收投屏、播放 App 投送的内容。
- 位置（仅在你主动点击"显示 Wi-Fi 名称"时申请）：Android 规定只有获得位置权限的 App 才能读取 Wi-Fi 名称。映湾只用它在主界面显示网络名称，不会读取或使用你的位置。
- 开机启动、前台服务：让映湾在电视开机后自动就绪，并在后台继续播放。

## 儿童隐私

映湾不收集任何人的个人信息，包括儿童。问题报告在发送前会去掉个人信息。

## 政策变更与联系方式

如果本政策有变更，我们会更新此页面及生效日期。如有问题，请在 [GitHub](https://github.com/weenas/castbay/issues) 上提交问题。
