- New "Desktop casting (CastBay Desktop)": turn it on in Settings and CastBay Desktop on a Windows or Linux computer can cast its screen and sound to the TV. The first connection asks for the 6-digit code the TV shows, after that it connects by itself; everything is encrypted. Off by default.
- Fixed the receiver staying on "Starting…" when the app is closed and opened again right away: if the system's local network discovery does not answer in time, registering is tried again.
- Fixed some TV boxes (an Android 9 one, for example) showing "Local network discovery failed (code 0)" as soon as the app starts: an internal error of the system is retried before it is reported.
